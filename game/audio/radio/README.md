# SA NU FM

Drop songs in this folder (`.ogg` or `.mp3`) and they play on the car radio, in file-name order. Press R in the car to skip.

Name files so they sort in album order, for example:

```
01 Scene I - Summer '10.ogg
02 Welcome to Paradise.ogg
```

`.ogg` is smallest. Keep each file under 100 MB (GitHub's limit).
