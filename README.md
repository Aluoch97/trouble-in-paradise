# Trouble in Paradise

A GTA-inspired, open-world story game based on Nicólas Soul's 2018 album *Trouble in Paradise*. Every mission is a track. You play Nick over one summer in Paradise, caught between Janae and Jessica, until the summer ends on the road to L.A.

© 2018 NuRenaissance. Private project.

## What's in here

| Folder | What it is |
| --- | --- |
| `docs/design-doc.md` | Story, characters, the 12 missions (one per track), game systems, roadmap |
| `prototype/web-isometric/` | The first playable demo of mission 2, *Welcome to Paradise*. Open `index.html` in any browser. |
| `game/` | The real game: a Godot 4 project (3D, third-person). Coming in the next commit. |
